# Saif Ullah — Remote Sensing & GIS Portfolio

A responsive static portfolio site designed for deployment on Vercel. It includes a home page, selected-work page, experience timeline, education, training, skills, publication, geographic footprint and contact links. The map-inspired illustrations are original decorative SVG/CSS graphics and do not represent operational or classified map data.

## Preview locally

Open `index.html` in a browser. The site uses Google Fonts when an internet connection is available and falls back to system fonts otherwise.

## Publish to Vercel

Deploy this folder as a static site to Vercel while signed in to the account that owns `geospa.vercel.app`. The preferred route is to update the existing project's source so its current domain remains attached. If the project is managed from a connected Git repository or v0 workspace, update that source and deploy the resulting production build.

The page includes the two email addresses and both phone numbers requested for public display. It omits the street address and exact home coordinates.
